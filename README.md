# Safety Quiz App

Static, client-side quiz app designed for GitHub + Netlify deployment.

## Local Run

1. From repo root, run the preview server script:
   - PowerShell: ./scripts/serve_preview.ps1
2. Open:
   - http://localhost:8080/Additional%20Codes/safety-quiz-app/

## Netlify Deployment

If this repository root is connected to Netlify:

- Build command: (leave blank)
- Publish directory: Additional Codes/safety-quiz-app

This project is pure static HTML/CSS/JS, so no build tooling is required.
